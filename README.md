## 頁面上有什麼

- **每個地點都有「地圖」連結** — 開 Naver Map 搜該地點的韓文名；手機上裝了 Naver Map 會直接跳 App。
- **配色切換** — 右上角按鈕在「跟隨系統 → 淺色 → 深色」之間循環，選擇記在該裝置上。
- **旅行當天會自己標出來** — 11/09–11/13 期間，當天的 Day 區塊和導覽列會亮起「今天」。
- **列印 / 存成 PDF** — 有專屬的列印樣式：去掉導覽、動畫與照片，一天一頁。網路不通的時候可以靠紙本。
- **出發前清單** — 勾選狀態存在瀏覽器的 `localStorage`，**各裝置獨立**；在 Claude Artifact 環境則會透過共用資料庫同步。

## 開發備註

`index.html` 同時服務兩個地方：

1. **GitHub Pages** — 直接提供原始檔，所以檔頭的 `<!doctype>`、`viewport`、`og:*` 等標籤是必要的，少了 viewport 手機版會縮小、少了 doctype 表格字體會跑掉。
2. **Claude Artifact** — 平台會自己包一層 `<head>`，檔頭那些標籤在該環境被忽略，不影響顯示。另外 `fonts/` 是相對路徑，在 Artifact 環境載不到，字型會退回系統的 PingFang TC／微軟正黑體，版面不受影響。

### 字型

本來從 Google Fonts 載完整的 Noto Sans TC / Noto Serif TC，光字型就是 **約 3 MB、46 個請求**——整頁最貴的一筆，而且在國外的網路上特別痛。現在改成自架子集：把上游的可變字型裁到「這頁真的會用到的約 1,150 個字」，三個檔案 **約 450 KB**，同源、沒有第三方連線。

**改動 `index.html` 的文字之後**，如果加進了本來沒有的字，那幾個字會悄悄退回系統字型。這時重跑：

```sh
pip install fonttools brotli
python tools/build-fonts.py
```

腳本會從 github.com/google/fonts 抓上游可變字型、裁掉用不到的字重區間、依 `index.html` 的字元集輸出 woff2，並一併更新 OFL 授權檔。
