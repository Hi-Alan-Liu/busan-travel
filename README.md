## 開發備註

`index.html` 同時服務兩個地方：

1. **GitHub Pages** — 直接提供原始檔，所以檔頭的 `<!doctype>`、`viewport`、`og:*` 等標籤是必要的，少了 viewport 手機版會縮小、少了 doctype 表格字體會跑掉。
2. **Claude Artifact** — 平台會自己包一層 `<head>`，檔頭那些標籤在該環境被忽略，不影響顯示。

行程清單的勾選狀態在 GitHub Pages 上存在瀏覽器的 `localStorage`，**各裝置獨立**；在 Artifact 環境則會透過共用資料庫同步。
